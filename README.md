# windware

A minimal front-end boilerplate.

## Files

- `index.html` — Main entry point.
- `css/style.css` — Styles: dark theme with orange/teal accents.
- `js/main.js` — Core interactivity.

## Quick Start

```bash
cd /path/to/windware
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
